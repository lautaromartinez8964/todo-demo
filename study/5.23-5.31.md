# 📅 10天零基础 Gin & CRUD 通关计划

## 🔵 第一阶段：掌握 Web 基础与 Gin（5月23日 ～ 5月25日）

### **Day 1 (5月23日)：理解 HTTP 极简概念与 Gin 的“Hello World”**
*   **今日目标**：理解什么是 API，让你的 Go 代码在浏览器里吐出数据。
*   **概念通俗化**：
    *   **HTTP 协议**：就像你去餐馆点菜。你（客户端/浏览器）向服务员（服务器）报菜名（**发送请求 Request**），服务员把菜端给你（**返回响应 Response**）。
    *   **GET 请求**：你去餐馆问“今天有什么特色菜？”（获取数据）。
    *   **URL（路由）**：不同的菜品窗口，比如 `/beef` 代表牛肉窗口，`/fish` 代表鱼肉窗口。
*   **动手实践**：
    1.  新建一个空文件夹 `todo-demo`，在终端运行以下命令初始化：
        ```bash
        go mod init todo-demo
        go get -u github.com/gin-gonic/gin
        ```
    2.  新建 `main.go`，**直接复制**以下代码：
        ```go
        package main

        import "github.com/gin-gonic/gin"

        func main() {
            // 1. 创建一个默认的路由引擎
            r := gin.Default()

            // 2. 绑定路由：当浏览器访问 GET /hello 时，执行后面的函数
            r.GET("/hello", func(c *gin.Context) {
                // 返回一个状态码为 200 (OK) 的 JSON 数据
                c.JSON(200, gin.H{
                    "message": "Hello Go Web!",
                })
            })

            // 3. 启动 HTTP 服务，默认在本地 8080 端口
            r.Run(":8080")
        }
        ```
    3.  运行 `go run main.go`。
    4.  打开浏览器，访问：`http://localhost:8080/hello`，如果页面显示 `{"message":"Hello Go Web!"}`，恭喜你，你完成了人生中第一个 API！
*   **今日作业（修改测试）**：
    *   修改代码，新增一个路由 `/ping`，让它返回 `{"status": "alive"}`。

### **Day 2 (5月24日)：学会向服务器传递数据（Query 与 JSON）**
*   **今日目标**：学会如何从浏览器接收用户传过来的数据。
*   **概念通俗化**：
    *   **Query 参数**：在网址后面用 `?` 拼接的参数，如 `/search?keyword=golang`。
    *   **JSON 格式**：目前前后端交互最通用的数据格式，长这样：`{"title": "学Go", "status": false}`。
*   **动手实践**：
    1.  修改 `main.go`，体验获取 Query 参数：
        ```go
        r.GET("/user", func(c *gin.Context) {
            // 获取网址里 ?name=xxx 的值，如果没有传，默认是 "Guest"
            name := c.DefaultQuery("name", "Guest")
            c.JSON(200, gin.H{
                "welcome": "Hello " + name,
            })
        })
        ```
        *测试方式*：访问 `http://localhost:8080/user?name=Jack`
    2.  下载并安装测试工具 **Postman**（或者在 VS Code 中安装 **REST Client** 插件），因为浏览器无法直接发送 POST 请求（用来提交数据的请求）。

---

### **Day 3 (5月25日)：接收 POST 请求与 Go 的结构体绑定**
*   **今日目标**：用户提交一个复杂的 JSON，Go 怎么接收？
*   **动手实践**：
    1.  在代码中定义一个结构体（Struct）来接收数据：
        ```go
        type TodoInput struct {
            Title string `json:"title"` // 这里的 json 标签代表前端传来的字段名
        }
        ```
    2.  编写 POST 路由：
        ```go
        r.POST("/todo", func(c *gin.Context) {
            var input TodoInput
            // ShouldBindJSON 会自动把前端传来的 JSON 绑定到 input 结构体上
            if err := c.ShouldBindJSON(&input); err != nil {
                c.JSON(400, gin.H{"error": err.Error()})
                return
            }
            c.JSON(200, gin.H{
                "status": "success",
                "received_title": input.Title,
            })
        })
        ```
    3.  用 Postman 模拟发送 POST 请求到 `http://localhost:8080/todo`，Body 选择 `raw` -> `JSON`，发送：`{"title": "学习Gin"}`。

### **Day 5 (5月27日)：GORM 登场——用 Go 代码连接数据库**
*   **今日目标**：不用写 SQL 语句，直接通过 Go 的结构体在数据库里自动建表。
*   **概念通俗化**：
    *   **GORM** 是一个 ORM 框架。它的作用是：**把 Go 里的一个结构体（Struct），映射为数据库里的一张表**；把结构体的一个实例，映射为表里的一行数据 [2]。
*   **动手实践**：
    1.  运行安装：
        ```bash
        go get -u gorm.io/gorm
        go get -u gorm.io/driver/mysql
        ```
    2.  写一段连接数据库的代码（先不要管复杂的配置，复制能跑通最重要）：
        ```go
        package main

        import (
            "gorm.io/driver/mysql"
            "gorm.io/gorm"
        )

        // 定义我们的数据库模型
        type Todo struct {
            ID     uint   `gorm:"primaryKey"`
            Title  string `gorm:"not null"`
            Status bool   `gorm:"default:false"`
        }

        func main() {
            // 参考格式: "用户名:密码@tcp(IP:端口)/数据库名?charset=utf8mb4&parseTime=True&loc=Local"
            dsn := "root:你的密码@tcp(127.0.0.1:3306)/todo_db?charset=utf8mb4&parseTime=True&loc=Local"
            db, err := gorm.Open(mysql.Open(dsn), &gorm.Config{})
            if err != nil {
                panic("数据库连接失败: " + err.Error())
            }

            // 自动迁移：GORM 会根据 Todo 结构体，自动在数据库里建表
            db.AutoMigrate(&Todo{})
        }
        ```
    3.  运行此代码，然后去你的数据库管理工具里刷新，看看是不是多了一张叫 `todos` 的表？

---

### **Day 6 (5月28日)：用 GORM 实现增删改查（CRUD）单体测试**
*   **今日目标**：不结合 Gin，先在 `main.go` 里写几行 GORM 代码，往数据库里塞数据、改数据。
*   **代码模仿**：
    ```go
    // 1. 增 (Create)
    newTodo := Todo{Title: "学算法", Status: false}
    db.Create(&newTodo) // 这行代码会自动转成 INSERT INTO sql 语句并执行

    // 2. 查 (Read)
    var foundTodo Todo
    db.First(&foundTodo, 1) // 查找 ID 为 1 的数据

    // 3. 改 (Update)
    db.Model(&foundTodo).Update("Status", true) // 把刚才查出来的这条数据的状态改为 true

    // 4. 删 (Delete)
    db.Delete(&foundTodo) // 删除这条数据
    ```

rdb := redis.NewClient(&redis.Options{Addr: "localhost:6379"})
